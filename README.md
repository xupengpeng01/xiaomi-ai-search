# 小米 AI 文件搜索

基于 [Figma「小米 AI 文件搜索」](https://www.figma.com/design/kBGNcFrVUJ3F4hE9K8hFUy/Portfolio-2026?node-id=1424-120103) 的 Next.js、React 和 Tailwind CSS 网页演示。

## 从 GitHub 下载

项目中的 MP4 视频通过 [Git LFS](https://git-lfs.com/) 管理。克隆前请安装 Git LFS，然后运行：

```sh
git lfs install
git clone https://github.com/xupengpeng01/xiaomi-ai-search.git
cd xiaomi-ai-search
git lfs pull
```

已有完整本地视频的项目可直接按下方步骤预览。

## 本地预览

在项目目录中打开终端，使用 Node.js 20.9 或更新版本。

```sh
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。也可以运行 `npm run build` 检查生产构建，然后运行 `npm start`。

## 试用路径

- 从首页选择「团建合照」「汽车漂移」「团建费用」「Adobe Photoshop 2026」或「本周待办」。展开历史可找到「Blender」。
- 点击设备 Tab 或文件类型切换结果。输入不存在的关键词可查看空状态。
- 点击结果可预览。右键或按 `Shift+F10` 可打开文件操作菜单，按 `Esc` 关闭预览。
- 点击历史标题旁的垃圾桶，可以逐条删除或清空记录。历史保存在当前浏览器中。
- 桌面窗口可最小化或关闭，点击任务栏可重新打开。窄屏下搜索窗口铺满浏览器。

## 交互假设

- 搜索和设备 Tab 使用本地演示数据。首页历史会切换到有匹配样例的设备，结果页会在当前设备内搜索。文件路径为示意。
- 原稿对部分设备使用了不同的型号名称，演示沿用首页的名称。原稿结果筛选中有两个「图片」按钮，演示保留两处并使用同一类结果。
- 照片、壁纸、媒体封面与多数组件图标来自 Figma 的独立图层。部分照片仅有缩略图可供预览，全部使用本地素材。界面优先使用系统已安装的 MiSans 常规、中等及半粗字重，未安装时回退到系统中文字体。可从 [小米官网下载 MiSans](https://hyperos.mi.com/font/download)。
- 「小米 SU7 上市发布会.mp4」读取 `public/videos/小米 SU7 上市发布会.mp4`，支持实际播放、暂停、跳转、倍速、音量、静音与下载，时长取自视频元数据。其它音视频使用原稿画面与演示控件。文件操作支持复制演示名称与路径、查看属性和保存可用素材。
- 汽车漂移片段采用提供的时间标注 `49:20–50:02`。默认从 `49:20` 播放，到 `50:02` 暂停，再次点击播放可重播该片段。进度条以 `#3482ff` 固定标记这段时间，两侧各留 `2px` 空隙。拖动到片段外可继续观看完整视频。
- 悬停或聚焦喇叭图标可调节音量，点击图标可静音或恢复音量。视频使用控制栏内的横向白色滑杆，音频使用带数值的白色竖向浮层。
- 视频工具栏的「保存当前帧」会将当前画面按视频原始分辨率下载为 PNG，文件名包含视频名称和时间点，播放状态保持原样。
